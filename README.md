
# TaskFlow

TaskFlow is a full-stack task management application
that helps users organize projects, manage tasks,
and track progress.

## Tech Stack

### Backend
- Node.js
- NestJS
- TypeScript
- PostgreSQL
- Prisma
- Docker

### Frontend
- React
- TypeScript
- Tailwind CSS

## Git Branches

- main: Production
- staging: Testing
- dev: Development
